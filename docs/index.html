Millennium Digest

Research results · numerical experiments on BSD and RH statistics (observations, not proofs)

Every Monday: the new arXiv papers on the seven Millennium Prize problems, on one page. Plus a helper that keeps emails to researchers polite, rare and hand-sent.

Python, standard library only Windows Task Scheduler arXiv API Drafts only, never auto-sends
View the code on GitHub

Weekly digest

Searches arXiv for the last 8 days on each problem, plus two narrower topics (elliptic-curve murmurations, Riemann-zero spacing), and flags changes on the Clay problems page and two data sources.

Outreach guard

Checks every draft to a researcher against written rules before opening a Gmail compose window, and keeps a ledger of who was contacted and when.

Honest scope

A hobby tool by an engineer, not a mathematician. It collects and organises; it does not solve or claim progress on any Millennium problem.

Outreach rules

From outreach_policy.json. A draft that breaks any rule is refused.

  • Sends automatically, but only emails that pass every rule below (otherwise it stays a draft)
  • One recipient per email
  • At most 2 new contacts per 30 days
  • 180 days between contacts with the same person
  • At most 1 follow-up, after 21 days
  • Body under 420 words, with an AI-assistance disclosure
  • A "no reply is needed" line and one specific question
  • Must cite the researcher's own work and a public source for their address

Run it

copy config.example.json config.json
python millennium_monitor.py      # writes and opens digests/digest_<date>.html
python outreach.py status         # ledger + what the rules allow next
python make_site.py               # rebuilds this page from the latest digest
